# 社長の右腕AI LP

GitHub Pages 用の静的LPです。

## 公開手順

1. GitHub の **Settings** を開く
2. **Pages** を選ぶ
3. **Build and deployment** で以下を選択
   - **Source**: Deploy from a branch
   - **Branch**: `main`
   - **Folder**: `/ (root)`
4. 保存後、数分で公開されます

公開URLの想定:

- `https://sgp-jp.github.io/shacho-migiude-ai/`

## ファイル構成

- `index.html` : LP本体
- `.nojekyll` : GitHub Pages 用設定
